ورق کثیر المشاہدہ پلیٹ فارم

A responsive multi-pane viewer for YouTube player testing and ordinary web pages. Paste multiple URLs, choose a layout, and control each pane independently.

LOCAL PLAYER QA
One pane per URL
Paste URLs above and select Load panes. Each URL creates one connected pane.

YouTube panes use the official embedded player. In Test loop mode, a video is restarted after its player reports ENDED; this is intended for player/localization QA, not for manufacturing engagement or watch-time metrics. Some websites block iframe embedding.
